IoT Smart Traffic Management System

An IoT-based Smart Traffic Management System developed using ESP32, HC-SR04 Ultrasonic Sensors, LCD Display, LEDs, Buzzer, and ThingSpeak Cloud. The system detects vehicle density and dynamically controls traffic signals to improve traffic flow efficiency.

📌 Features
Real-time vehicle detection using ultrasonic sensors
Automatic traffic light control
LCD display for signal status and countdown timer
Buzzer alert system
Cloud-based monitoring using ThingSpeak
Wi-Fi connectivity via ESP32
Live traffic data visualization
🛠 Hardware Components
ESP32 Development Board
2 × HC-SR04 Ultrasonic Sensors
16x2 LCD Display (I2C)
Red, Yellow, and Green LEDs
Buzzer
Jumper Wires

🚀 Working Principle
Ultrasonic sensors continuously monitor vehicle presence.
ESP32 processes traffic density data.
Traffic lights are controlled based on detected traffic.
LCD displays lane status and timer information.
Traffic data is uploaded to ThingSpeak via Wi-Fi.
Users can monitor traffic statistics remotely through the cloud dashboard.
